# New Crop Disease Classes Introduced to Taxonomy

These class IDs were added during the dataset expansion. They are ready to be integrated into the Android app's `app/src/main/assets/knowledge_base.json`.

---

## List of New Class IDs

| Class ID | Crop Name (English / Hindi) | Condition / Disease Name | Description |
| :--- | :--- | :--- | :--- |
| `Apple___cedar_apple_rust` | Apple (सेब) | Cedar Apple Rust (केडार सेब रस्ट) | Fungal disease (*Gymnosporangium juniperi-virginianae*) causing bright orange-yellow spots on upper leaf surfaces. |
| `Blueberry___healthy` | Blueberry (ब्लूबेरी) | Healthy (स्वस्थ) | Normal, healthy blueberry foliage with no disease symptoms. |
| `Cherry___powdery_mildew` | Cherry (चेरी) | Powdery Mildew (पाउडर संक्रामक / चूर्णिल आसिता) | Fungal growth (*Podosphaera clandestina*) forming white powdery patches on leaves and shoots. |
| `Cherry___healthy` | Cherry (चेरी) | Healthy (स्वस्थ) | Healthy cherry tree leaf. |
| `Citrus___citrus_greening` | Citrus / Orange (संतरा / नींबू) | Citrus Greening / Huanglongbing (सिमट्रस ग्रीनिंग / एचएलबी) | Bacterial disease (*Candidatus Liberibacter*) causing yellow veins, mottled asymmetrical chlorosis, and dieback. |
| `Citrus___healthy` | Citrus / Orange (संतरा / नींबू) | Healthy (स्वस्थ) | Healthy citrus leaf. |
| `Grape___leaf_blight` | Grape (अंगूर) | Leaf Blight / Isariopsis Spot (लीफ ब्लाइट / इसारियोप्सिस धब्बा) | Fungal lesions (*Pseudocercospora vitis*) forming dark brown, angular dead patches on leaves. |
| `Peach___bacterial_spot` | Peach (आडू) | Bacterial Spot (जीवाणु धब्बा रोग) | Bacterial infection (*Xanthomonas arboricola*) leading to dark water-soaked spots that drop out ("shot-hole"). |
| `Peach___healthy` | Peach (आडू) | Healthy (स्वस्थ) | Healthy peach tree leaf. |
| `Raspberry___healthy` | Raspberry (रास्पबेरी) | Healthy (स्वस्थ) | Healthy raspberry plant leaf. |
| `Rice___bacterial_panicle_blight` | Rice / Paddy (धान) | Bacterial Panicle Blight (जीवाणु जनित पैनेकल ब्लाइट) | Bacterial disease (*Burkholderia glumae*) causing grain discoloration, panicle blighting, and sterility. |
| `Rice___leaf_smut` | Rice / Paddy (धान) | Leaf Smut (लीफ स्मट / पर्ण कण्ड) | Fungal disease (*Entyloma oryzae*) creating tiny, raised, black rectangular spots on rice leaves. |
| `Soybean___healthy` | Soybean (सोयाबीन) | Healthy (स्वस्थ) | Healthy soybean plant leaf. |
| `Squash___powdery_mildew` | Squash / Gourd (कद्दू / स्कवैश) | Powdery Mildew (चूर्णिल आसिता) | White talcum-like fungal powder (*Podosphaera xanthii*) covering upper and lower leaf surfaces. |
| `Squash___healthy` | Squash / Gourd (कद्दू / स्कवैश) | Healthy (स्वस्थ) | Healthy squash leaf. |
| `Strawberry___leaf_scorch` | Strawberry (स्ट्रॉबेरी) | Leaf Scorch (स्ट्रॉबेरी लीफ स्कॉर्च / पर्ण दाह) | Fungal spots (*Diplocarpon earlianum*) starting as dark purple blurs and turning scorched brown. |
| `Strawberry___healthy` | Strawberry (स्ट्रॉबेरी) | Healthy (स्वस्थ) | Healthy strawberry plant leaf. |
