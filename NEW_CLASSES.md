# New Crop Disease Classes Introduced to Taxonomy

These class IDs were added during the dataset expansion. They are ready to be integrated into the Android app's `app/src/main/assets/knowledge_base.json`.

---

## List of New Class IDs

| Class ID | Crop Name (English / Hindi) | Condition / Disease Name | Description |
| :--- | :--- | :--- | :--- |
| `Apple___cedar_apple_rust` | Apple (सेब) | Cedar Apple Rust (केडार सेब रस्ट) | Fungal disease (*Gymnosporangium juniperi-virginianae*) causing bright orange-yellow spots on leaves. |
| `Cherry___powdery_mildew` | Cherry (चेरी) | Powdery Mildew (पाउडर संक्रामक / चूर्णिल आसिता) | Fungal growth (*Podosphaera clandestina*) forming white powdery patches. |
| `Cherry___healthy` | Cherry (चेरी) | Healthy (स्वस्थ) | Healthy cherry foliage. |
| `Grape___leaf_blight` | Grape (अंगूर) | Leaf Blight / Isariopsis Spot (लीफ ब्लाइट / इसारियोप्सिस धब्बा) | Fungal spots (*Pseudocercospora vitis*) causing dark brown angular dead lesions. |
| `Peach___bacterial_spot` | Peach (आडू) | Bacterial Spot (जीवाणु धब्बा) | Bacterial spots (*Xanthomonas arboricola*) leading to shot-hole lesions. |
| `Peach___healthy` | Peach (आडू) | Healthy (स्वस्थ) | Healthy peach leaf. |
| `Rice___bacterial_panicle_blight` | Rice / Paddy (धान) | Bacterial Panicle Blight (जीवाणु जनित पैनेकल ब्लाइट) | Bacterial disease (*Burkholderia glumae*) causing grain discoloration and kernel abortion. |
| `Rice___leaf_smut` | Rice / Paddy (धान) | Leaf Smut (लीफ स्मट / पर्ण कण्ड) | Fungal disease (*Entyloma oryzae*) creating tiny raised black rectangular spots. |
| `Strawberry___leaf_scorch` | Strawberry (स्ट्रॉबेरी) | Leaf Scorch (स्ट्रॉबेरी पर्ण दाह) | Fungal spots (*Diplocarpon earlianum*) turning dark purplish-red to scorched brown. |
| `Strawberry___healthy` | Strawberry (स्ट्रॉ贝री) | Healthy (स्वस्थ) | Healthy strawberry plant leaf. |
